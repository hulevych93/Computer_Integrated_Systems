## Матеріали

| Файл | Призначення |
|---|---|
| `kik_praktyka_05.pptx` | презентація заняття |

### Каркаси (`scripts/`)

| Файл | Тема |
|---|---|
| `demo_01_def.py` | опис функції через `def`, виклик, порядок опису й виклику |
| `demo_02_return.py` | параметри, `return`, різниця між `print` і `return` |
| `demo_03_params.py` | кілька параметрів, значення за замовчуванням, іменовані аргументи |
| `demo_04_refactor.py` | розбиття готової програми на функції |

## Що вивчаємо

- конструкція `def`: опис функції та її виклик
- чому опис має бути вище за виклик
- параметри й аргументи, передача даних усередину функції
- `return` — повернення результату назовні
- різниця між `print` і `return`, і чому функція має повертати значення
- кілька `return` в одній функції
- значення параметрів за замовчуванням та іменовані аргументи
- повернення кількох значень одразу
- область видимості: локальні змінні
- докстрінги та підказки типів
- розбиття задачі на функції: одна функція — одна дія

## Головна ідея заняття

Задача четвертого заняття — звіт про серію вимірювань — переписується на функції.

## Контрольні точки для перевірки

| Скрипт | Перевірка | Очікуваний результат |
|---|---|---|
| `demo_02` | оберненість перетворення для 36.6 | `True` |
| `demo_03` | `to_current(125)` для діапазону 0–250 кПа | рівно 12.00 мА |
| `demo_03` | `to_current(0)` і `to_current(250)` | 4.00 і 20.00 мА |
| `demo_04` | серія 20, 25, 70, 18, −50 | середнє 16.600, розмах 120.000, поза допуском 2 з 5 |

Прийом, який застосовуємо до кінця курсу: функцію перевіряють
викликом зі значенням, для якого відповідь відома наперед.
