# Заняття 7. Словники

## Матеріали

| Файл | Призначення |
|---|---|
| `kik_praktyka_07.pptx` | презентація заняття |
| `scripts/` | каркаси для роботи на парі |

### Каркаси (`scripts/`)

| Файл | Тема |
|---|---|
| `demo_01_dict_basics.py` | створення словника, доступ за ключем, зміна й додавання пар |
| `demo_02_passport.py` | прохід через `items`, перевірка ключа через `in` та `get` |
| `demo_03_counter.py` | словник як лічильник за категоріями |
| `demo_04_journal.py` | список словників: журнал вимірювань |

## Що вивчаємо

- словник як набір пар «ключ: значення»; створення та порожній словник
- доступ за ключем, зміна наявного значення, додавання нової пари
- `len` — кількість пар
- `KeyError` і два способи його уникнути: оператор `in` та метод `get`
- прохід циклом: `keys`, `values`, `items`
- словник-лічильник: підрахунок за категоріями без переліку наперед
- список словників як таблиця даних у пам'яті
- сортування списку словників через параметр `key` з іменованою функцією
- повернення словника з функції замість кількох окремих значень
- пастки: друкарська помилка в ключі, повторний ключ, вимоги до ключа

## Головна ідея заняття

Список відповідає на питання «яке значення на позиції 2». Словник —
на питання «яка верхня межа діапазону». Серія вимірювань лишається
списком, бо всі її елементи однорідні; паспорт датчика описується
словником, бо кожне значення має власний зміст.

Передача функції як аргументу (`sorted(journal, key=get_value)`) —
нова ідея цього заняття: функція теж значення, яке можна передати.

## Контрольна серія

**20, 25, 70, 18, 150** при уставках `lo = -40`, `hi = 60`, `alarm = 100`.

| Вимір | Значення | Стан |
|---|---|---|
| 1 | 20.0 | НОРМА |
| 2 | 25.0 | НОРМА |
| 3 | 70.0 | ПОПЕРЕДЖЕННЯ |
| 4 | 18.0 | НОРМА |
| 5 | 150.0 | АВАРІЯ |

Підсумок за станами: НОРМА 3 (60.0 %), ПОПЕРЕДЖЕННЯ 1 (20.0 %),
АВАРІЯ 1 (20.0 %).

Порядок номерів після сортування за значенням: 4 1 2 3 5.
