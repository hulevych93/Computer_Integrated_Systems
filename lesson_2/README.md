# Заняття 2. Ввід і вивід. Типи даних. Рядки

## Матеріали

| Файл | Призначення |
|---|---|
| `kik_praktyka_02.pptx` | презентація заняття |
| `scripts/demo_01_print.py` | вивід у консоль: `print`, `sep`, `end` |
| `scripts/demo_02_numbers.py` | змінні, `int` і `float`, перетворення типів |
| `scripts/demo_03_input.py` | ввід з клавіатури, конвертор температури |
| `scripts/demo_04_strings.py` | рядки, f-рядки, методи, індекси та зрізи |

Скрипти з теки `scripts/` — це те, що ми пишемо разом на парі.
Кожен файл запускається самостійно.

## Що вивчаємо

- функція `print()`: кілька значень, параметри `sep` і `end`
- змінні: правила іменування, присвоєння, зміна значення
- числові типи `int` і `float`, операції `/`, `//`, `%`, `**`
- перетворення типів: `int()`, `float()`, `str()`, `round()`
- функція `input()` і чому вона завжди повертає рядок
- рядки: довжина, конкатенація, повторення
- f-рядки та форматування чисел: `f"{x:.3f}"`
- методи рядків: `strip`, `upper`, `lower`, `replace`, `split`, `count`
- індекси та зрізи рядків
- чотири найчастіші помилки: `SyntaxError`, `NameError`, `TypeError`, `ValueError`

## Як запустити скрипт

1. Відкрити теку курсу у VS Code: `File → Open Folder`
2. Відкрити потрібний файл `.py`
3. Натиснути кнопку ▷ у правому верхньому куті або клавішу `F5`
4. Результат з'явиться в панелі `Terminal` унизу
