## Що вивчаємо

- список як впорядкований набір значень; створення та порожній список
- індекси та зрізи — такі самі, як у рядків
- чим список відрізняється від рядка: елементи можна змінювати
- `append`, `insert`, `remove`, `pop` і зміна за індексом
- прохід циклом по значеннях і через `enumerate`
- вбудовані функції `sum`, `len`, `min`, `max`
- сортування: `sorted` повертає новий список, `sort` змінює наявний
- медіана та її відмінність від середнього
- фільтрація: відбір значень за умовою в новий список
- передача списку у функцію та повернення списку
- пастки: присвоєння не копіює список, `IndexError`, порожній список

## Головна ідея заняття

На четвертому занятті кожне значення зникало одразу після зчитування,
тому можна було порахувати лише суму, мінімум і максимум. Усе, що
вимагає другого проходу по даних — сортування, медіана, порівняння
кожного виміру із середнім по серії — потребує збереження.

Накопичення в циклі при цьому не застаріло: воно лишається єдиним
способом обробки, коли дані не поміщаються в пам'ять.

## Контрольна серія

Та сама, що на заняттях 4 і 5: **20, 25, 70, 18, −50** при допуску
−40 … 60 °C.

| Величина | Значення |
|---|---|
| сума | 83.000 |
| середнє | 16.600 |
| медіана | 20.000 |
| мінімум / максимум | −50.000 / 70.000 |
| розмах | 120.000 |
| придатні | `[20.0, 25.0, 18.0]` |
| відбраковані | `[70.0, -50.0]` |
| середнє по придатних | 21.000 |

Порівняння середнього й медіани на цій серії наочне: один грубий
промах −50 зміщує середнє до 16.6, тоді як медіана лишається 20.0.
