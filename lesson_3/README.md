для запису під час пари.

## Що вивчаємо

- тип `bool`, значення `True` і `False`
- шість операторів порівняння: `==`, `!=`, `>`, `<`, `>=`, `<=`
- чому дійсні числа не порівнюють через `==` і як порівнювати правильно
- логічні операції `and`, `or`, `not` та їх таблиці істинності
- ланцюжки умов: `T_MIN <= t <= T_MAX`
- пріоритет логічних операцій і навіщо потрібні дужки
- конструкції `if`, `if/else`, `if/elif/else`
- роль відступів у синтаксисі Python
- порядок перевірок у ланцюжку `elif` і недосяжні гілки
- конструкція `match` / `case` — аналог `switch`; коли вона доречніша за `elif`
- валідація вхідних даних перед обчисленням
- типові помилки: `=` замість `==`, забута двокрапка, `IndentationError`, `TabError`
